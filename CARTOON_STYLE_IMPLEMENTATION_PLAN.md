# Cartoon Style Pipeline Implementation Plan

Add a user-selectable `realistic`/`cartoonish` style to the existing asynchronous job flow.

- `realistic` remains the current behavior.
- `cartoonish` sends the normalized input through Vertex AI Gemini first, then runs a future outline-only renderer.
- Selecting `cartoonish` in the frontend automatically selects `outline_only`; users do not choose a separate cartoon color-guide mode.
- Cartoonish is disabled by default behind feature flags.
- Vertex AI failures fail the job explicitly; there is no silent fallback to realistic.
- Cartoonish is organizer-only and always consumes one credit from the selected personal or event pool.
- Attendees and anonymous users cannot use cartoonish; the backend remains authoritative and the frontend shows a disabled option.
